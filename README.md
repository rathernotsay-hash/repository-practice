## Git Research

### What is a Git branch and why is it useful?

A Git branch is an independent line of development that allows developers to work on changes without directly modifying the main branch. Branches are useful because developers can develop and test new features separately before merging them into the main project.

### What is a Pull Request and why do teams use it?

A Pull Request is a request to merge changes from one branch into another branch, usually the main branch. Teams use Pull Requests so that other developers can review, discuss, and approve changes before they are merged.

### Git Merge vs Git Pull

`git merge` combines changes from one branch into another branch. `git pull` downloads changes from a remote repository and integrates them into the current local branch.
